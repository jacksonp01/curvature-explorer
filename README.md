# Curvature Explorer

An in-browser explorer for a curvature measure of room photos. Change the measure's settings and see how the contours, each room's score
and the correlation with people's curvedness ratings change. The measure is computed by the original Python code, run in the browser
with [Pyodide](https://pyodide.org) (numpy, scipy, scikit-image in WebAssembly). No server is involved.

## The measure (N)
1. **Surface normals**: Marigold-Normals v1.1 (Ke et al. 2025; 4 denoising steps, ensemble 1, seed 0), computed in advance for every photo
   and stored at the photo's own size (`data/rooms/normals/*.npz`, float16).
2. **Canny edges** on each of the three normal components (Gaussian σ, hysteresis thresholds at quantiles of the gradient magnitude),
   OR-ed, thinned and traced into chains between junctions; chains shorter than a minimum length are dropped.
3. **A/A+C window classifier**: each chain is resampled every 2 px, smoothed (σ = fraction × W) and its tangent angle median-filtered;
   every window of W px is labelled straight, corner, arc or jagged from its turning.
4. **Score = arc / (arc + corner)** points, pooled over the image.

With the default settings, the 191 rooms give Pearson r +0.667 with mean curvedness ratings (Spearman ρ +0.657; round vs square
Cohen's d +1.20).

## Files
```
index.html style.css app.js   page, drawing, statistics, worker pool
worker.js                      one Pyodide instance per Web Worker
py/global_curv.py              the project's contour code (copied unchanged)
py/explorer.py                 the pipeline with its settings exposed
data/rooms/manifest.json       per room: rating, round/square label, source, size, default score
data/rooms/{photos,thumbs,normals}/
```
`py/explorer.py` traces each chain from its smallest end point, so the browser (32-bit WebAssembly) and desktop Python give identical
scores. Every room's default score in the browser equals `n_default` in the manifest. The research code picks the start point in
Python-set order; this changes 34 rooms by at most 0.008 (`n_research`; r +0.6671 vs +0.6668 here).

## Run locally
Any static file server works, e.g. `python3 -m http.server 8000` in this folder, then open http://localhost:8000.
The first visit downloads Pyodide and its packages (about 40 MB). Scoring every room downloads all normal maps (about 410 MB) and takes
about 30 s with 4-5 workers.

The site is generated by `scripts/web_export/export.py` in the research repository (AlignedCurvaturePerception). Its
`scripts/web_export/parity.py` checks the bundle against the research code.
